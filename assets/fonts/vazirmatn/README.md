The official standard build combines Persian/Arabic glyphs with Roboto Latin glyphs. This one variable font supplies weights 100–900 for both interface languages; no Apple font is redistributed. Upstream documentation: https://github.com/rastikerdar/vazirmatn/tree/v33.003

The build embeds the WOFF2 as a CSS data URL and embeds this attribution and the full OFL in an inert HTML template, viewable in the source. Generic and private copies carry it together. No CDN, installed-font lookup, runtime font request or companion file is required. The repository assets are build inputs only.
