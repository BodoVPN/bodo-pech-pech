What this file does and does not protect

        
This file uses your browser’s AES-256-GCM encryption with a fresh random nonce per message. Exact bytes are packed losslessly before encryption when that saves space. Persian dialogue rules carry the encrypted bytes; the rules are not encryption. The cover exposes its theme, reply style and packed message size.

        
There is no forward secrecy, replay protection, sender identity proof, or protection against a compromised device, browser extension, keyboard, clipboard service, or altered copy of this HTML file. A leaked pair code exposes past and future messages made with it. Use a separate new code for each pair.

        
The file makes no network requests, installs nothing, and does not save keys, messages, or context to browser storage. Browser and operating-system memory, session recovery, input history, and the clipboard are outside that guarantee. Clearing drops references; secure memory erasure is not guaranteed.

        
Keep a trusted copy of this HTML file. Open it directly in a full browser; file previewers may not run JavaScript. Windows Chrome and Edge are tested. Galaxy A51-class Android phones are a design target, but actual Android file handling and performance still need device testing.
